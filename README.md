# Little Learners Studio™

A premium education platform starring **Bella the Brave Bunny**, built for
parents, teachers, tutors, homeschool educators, and daycare owners.

## Getting started

```bash
npm install
cp .env.example .env.local # fill in Supabase/Stripe/Cloudinary keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tech stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion ·
Lucide React · Supabase · Stripe · Cloudinary · Vercel

See [`docs/README.md`](./docs/README.md) for architecture, brand guidelines,
and the milestone build plan.
